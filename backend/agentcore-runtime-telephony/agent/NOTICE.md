# Notice — Telephony Agent Container Third-Party Attribution

This container image bundles third-party code. Attribution + license notes below.

## Vendored code

### `vendored/kvs_parser/`

A thin adapter over the `ebmlite` library for decoding Kinesis Video Streams
MKV/EBML fragments produced by Chime Voice Connector. See
`vendored/kvs_parser/NOTICE.md` for the full attribution + SHA pin.

## Runtime pip deps

Top-level pins live in `requirements.txt`; the full transitive tree + hashes
are regenerated by CodeBuild and written to `requirements.lock` (NFR3 / P8).

## Fallback audio

`fallback/apology.wav` is generated at Docker build time by
`fallback/generate_apology.py` — 0.5s of 8 kHz μ-law silence, royalty-free.
The pre-deploy BucketDeployment in task 5.4 uploads this file to the playback
bucket at `{DEPLOYMENT_PREFIX}/fallback/apology.wav`.
